# 变体层（窗口内排序）：分层口径与验收

> 日期：2026-09-12 · 状态：**已落地**（`configs/stages.yaml: ranking.variant_layer.enabled = true`）
> 代码：`src/sirna_pipeline/stages/rank/ranker.py`（`c_match` / `variant_band` / run_rank §4b）
> 验收脚本：`scripts/verify_variant_layer.py` → `outputs/analysis/variant_layer_verification.json`
> 标定来源：`outputs/analysis/mismatch/mismatch_cmatch_calibration_v2.json`
> 证据：`outputs/analysis/mismatch/qguide_variant_signal.json`、`docs/design/qguide_variant_signal.md`

## 1. 为什么要分层

原实现把**所有行**（WT 与 15 个单点突变体）放进同一个加权和：

```
final_score = α·score_thermo + β·score_oligo − penalty
```

这在"选窗口"上是对的（四基准集 mean ρ=0.569 已验证），但**在变体粒度上不成立**：

| 实测 | 数值 | 含义 |
|---|---|---|
| ΔQ_guide 符号 vs Δlabel 的符号准确率 | 0.558，置换 **p=1.000** | 变体级 Δ 无信息 |
| 提拔精度（模型说"变体能赢"且真赢） | **0/39**（Ohnishi 0/30） | 提拔全是空的 |
| Δthermal 与 Δoligo 符号一致率 | **0.42**（ρ=**−0.33**） | 两个信号方向相反 |
| DL 项占 ΔQ 方差 | **82.5%**（Ohnishi 66.7%） | β=0.6 使噪声项主导变体决策 |

即：**窗口级有效的模型，其分数差不能外推到同一个 guide 的单碱基突变体之间**。

## 2. 分层口径

```
窗口层（选窗口，口径不变）: Q_window = α·score_thermo + β·score_oligo      ← 已验证，勿动
变体层（窗口内选变体）    : final_score = ( Q_window(锚点) + 改善通道 ) × C_match − penalty
                                              └ γ·α·( score_thermo(变体) − score_thermo(WT) ) ┘
```

* **锚点** = 该窗口 **WT 行**的 `Q_window`；若 WT 未通过前序硬过滤 → 退化取窗口内最高（meta 记 `n_windows_fallback_anchor`）。
* **改善通道（关键）**：错配**不是纯损失**。5′ 端（尤其 g1/g2）错配削弱 guide 5′ 末端配对、
  修正链选择不对称性，可提高 RISC 装载与切割效率——这是文献已确立的机制，也是本项目中
  `delta_deltaG_ends`（5′−3′ 末端 ΔG 差）这一特征方向有效的原因。
  因此窗口内**冻结 DL 项**（其实测变体级 Δ 是噪声、且与热力反相关），只让**热力项随突变移动**：
  变体的热力改善可以补偿甚至超过 C_match 的折扣，从而**超过自己的 WT**。
  `mech_gain_weight`（γ）＝该通道强度：γ=0 即关闭（退化为"突变只降效率"），γ=1 与窗口层同权重。
  **该通道由机制与文献先验驱动，未用数据标定**——现有错配集不含 g1/g2 错配，
  且标签为 WT 归一化保留率（天花板 1.0），无法标定增益幅度。
* **C_match** = `Π_错配 (1 − λ_position × λ_type)`，WT（无错配）≡ **1.0**。
* **向后兼容**：WT 行 Δthermo≡0、C_match≡1 → 分数与旧口径**逐位一致**。

| 位置带 | λ | 标定样本 / 依据 |
|---|---|---|
| g1 | 0.0000 | **文献先验**（n=0）：该位在 RISC 中本不配对；Holen 9/9 例摆动**增益** |
| g2–g8 seed | 0.1786 | 拟合 n=24（最大样本）；文献只给"影响小/可加速"方向 |
| g9–g11 cleavage | **0.3082** | **文献先验覆盖弱拟合**（n=4）：Holen 第 10 位剧烈失活、AGO2 t9–t11 >500× |
| g12 | **0.1500** | **文献先验覆盖 n=2 拟合**：AGO2 t12 可省/t12A 更快 vs KRNB 9–13 须配对 → 折中 |
| g13–g16 mid | 0.1685 | 拟合 n=9；λ(g13)>λ(g12) 与 AGO2 一致 |
| g17–g19 p3 | 0.0000 | **文献先验**（n=0）：AGO2 t15–21 增益 + KRNB 白名单 {1,15,17,18,19,20,21} |

| 类型（AGO2 轴） | 因子（位置 ≤11 / ≥12） |
|---|---|
| WC（非错配） | 0 / 0 |
| GU 摆动 | 0.5 / 0.5（**纯先验**：文献无 GU 数值） |
| transition | 0.85 / **1.0** |
| transversion | 1.0 / **0.7** ← AGO2 报告该轴在 t12 处符号反转 |

|---|---|

> 无法提供可标定的逐位幅度）。`fitted` 与 `literature_prior` 逐带记入 meta 的 `lambda_source`。

`scripts/verify_variant_layer.py` 在 `outputs/runs/sfrp1_oligo_on` 的候选上双跑（on/off）：

| 验收项 | 结果 |
|---|---|
| 参与排序行 | 4218（WT 264 / 变体 3954） |
| **WT 行分数列差异（on vs off）** | **0 处 → 逐位一致 ✓** |
| **WT 行 vs 冻结 run `rank_reweighted`** | **0 处差异 ✓** |
| 变体行 `final = 锚点×C_match − penalty` | 3954/3954 全部通过 ✓ |

**这就是"不破坏冻结结果"的证明**：WT 行（= 窗口选择结果）与发布口径完全一致，
改变的只有窗口内变体的相对次序。

## 4. 行为变化

| 口径 | Top-20 Jaccard vs 冻结 | Top-50 Jaccard vs 冻结 | 超过本窗口 WT 的变体数 |
|---|---|---|---|
| 仅 `×C_match`（**已废止**：该式禁止变体超过 WT） | 0.212 | 0.299 | **0** |
| `×(锚点+改善通道)×C_match`，λ 为**拟合值** | 0.212 | 0.370 | 389 |
| **`×(锚点+改善通道)×C_match`，λ 按文献校正（现行）** | **0.290** | **0.449** | **795 / 3954** |

文献校正使"可增益位点"扩大（g1 与 p3 的 λ 归零、门控位点允许热力增益），
同时把中央区（最脆弱）的代价大幅上调（0.0942 → 0.3082）、g12 下调（0.3082 → 0.15）。
**WT 行仍逐位一致**（0 处差异），公式核对 3954/3954 通过。

**读法**：窗口层决定"哪条 siRNA 值得做"（WT 仍是最稳的起点，Top-3 都是 WT）；
变体层给出"若因特异性必须引入突变，代价是多少、有没有靠热力改善补回来"。
改善通道使 389/3954（≈10%）的变体在**自身热力改善足够**时反超 WT——这恢复了
"部分错配可提高效率"这一机制，而不是把它排除在模型之外。

> 需要区分两个计数口径：`n_variant_above_own_wt`=384 是**相对锚点**（含 275 个无 WT 的
> 退化锚点窗口）；验收脚本报的 389 是**相对该窗口真实 WT 行**（仅 264 个有 WT 的窗口）。

## 5. 已知边界（写进 Model Card）

1. **λ 的 g1 与 g17–g19 两带为纯先验**（标定集 n=0）：生产库恰好只突变 g1/g12/g17/g18/g19，
   其中 3/5 个位点的 λ 无数据支撑 —— 属"先验正则化"，不是拟合结果；
2. **g12 的 λ 仅由 n=2 支撑**（收缩后先验权重占 2/3）；
3. 标定集只有 **4 条 guide（Ohnishi PRNP 等位基因）**，外推到其它基因/修饰/多错配无依据
   （本层对多错配按连乘处理，但生产库当前只有单错配）；
4. **改善通道未标定**：γ（`mech_gain_weight`）由机制/文献先验设定，**没有数据支撑**——
   标定它需要 g1/g2 错配的实测，或独立于 WT 的绝对效力数据；
   当前错配集既不含 g1/g2 错配，标签又是 WT 归一化保留率（天花板 1.0），两者都做不到。
   因此该通道应视为**有界先验**，报告需给出 γ=0/0.5/1.0 的敏感性；
5. 窗口层 α/β 与权重**未改动**；本层可一键回退（`enabled: false`）。

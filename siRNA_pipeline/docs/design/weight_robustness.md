## 3. 结论

1. **对权重噪声鲁棒**：±20% 单权重扰动下 Top-20 Jaccard 最低 0.667、Top-50 最低 0.818，
   全体排序 ρ ≥ 0.998 → 排序结果不由单个权重的精确取值决定，权重无需精调。
2. **rank1 本身不稳定**：随机扰动中 69.5% 会改变 Top-1。**不应把"第 1 名"当作唯一答案解读**，
   应报告 Top-N 集合（设计上 Top-50 跨 31 个窗口，保留窗口多样性）。
3. **β 比单个权重重要得多**：β 从 0.6 移到 0.4/0.8 时 J20 掉到 0.29/0.38，
   远大于任何单权重扰动的影响。因此 α/β 只能由基准集证据决定
   （见 `ranking_weighting.md` 与 `outputs/analysis/weighting_sweep.json`），
   而不是靠权重微调。
4. **seed 权重置 0 是有依据的**：恢复 0.8（旧默认）会显著改变 Top-20（J20 0.429），
   而错配消融中 `dG_seed` 与标签负相关（ρ=−0.130），故关闭。

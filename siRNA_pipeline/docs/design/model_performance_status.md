## 一、全匹配基准集（task14：与实验效率的 Spearman，四数据集已补齐）

| 数据集 | 纯 DL（OligoFormer） | 纯热力（ranker 口径四特征） | 热力+DL（0.8/0.2） |
|---|---|---|---|
| Hu (n=2361) | **0.644** [0.620, 0.666] | 0.132 [0.092, 0.168] | 0.417 [0.377, 0.449] |
| Taka (n=702) | **0.565** [0.506, 0.623] | **−0.192** [−0.246, −0.102] | 0.096 [0.039, 0.180] |
| Mix (n=464) | **0.689** [0.638, 0.735] | 0.150 [0.062, 0.231] | 0.515 [0.447, 0.574] |
| **Simone (n=322)**（本次补齐） | **0.305** [0.194, 0.407] | 0.008 [−0.103, 0.120]（p=0.887） | 0.121 [0.012, 0.236] |

**四条硬结论**
1. 全匹配场景：**OligoFormer 远强于四特征热力分**（0.31–0.69 vs −0.19–0.15）；
2. α=0.8/β=0.2 的融合在**四个数据集上全都比纯 DL 差** → 当前生产权重不成立；
3. **Simone 很可能是 OligoFormer 训练集之外的"真外部集"**：DL 只有 0.305，而 Hu/Taka 高到 0.56–0.64（疑域内）
   → 干净口径下的诚实估计是 **DL ≈ 0.3、热力分 ≈ 0（p=0.887）**；
4. 热力分四个数据集为 0.132 / −0.192 / 0.150 / 0.008 → **不宜作为排序主分**。

## 六、修订后的判断

**能说**
1. **全匹配场景**：OligoFormer 排序一致性 ρ≈0.31–0.69（Simone 为真外部集 → 0.305；Hu/Taka 疑域内 → 0.56–0.64）；
2. **错配场景**：位置 Ridge 是当前最可靠预测器（LOSO/LOFO 0.57–0.75）；DL 在错配场景弱（≈0.18）；
3. **特征层面**：MFE 有信号（错配集 0.353）；**dG_seed 权重应为 0**（实测无正贡献）；
4. **权重已由证据确定**：α/β=0.4/0.6 + dG_seed 权重 0 → 四基准 mean ρ 0.287→**0.569**、最差集 0.096→0.323；
5. 管道稳定可复现；毒性/免疫惩罚实际生效。

**修正的错误结论**
- ~~"OligoFormer 未验证"~~ → 全匹配基准上它是最强单一预测器；仅错配场景弱；
- ~~"β=0.2 应维持"~~ → 已改为 **β=0.6**（纯 DL β=1.0 次之，旧 0.2 最差）；
- ~~"四特征等权/seed 0.8"~~ → `feat_dG_seed` 权重置 0。

**仍不能说**
- SFRP1 自身榜单的绝对效率（无实测标签）；
- Hu/Taka 是否为 OligoFormer 训练集（需查其训练脚本/论文；若确认则降级为域内一致性检查）。

## 3. 任务 1 · mRNA_57nt 构建

### 3.1 实现逻辑
- **siRNA 列方向**：经与 OligoFormer 官方仓库 `scripts/flanking_mRNA_symmetric.py` 的 `antiRNA()` 约定核对——**siRNA 列为 guide（反义）链**；同理，其互补反向链即为 **mRNA（sense）靶位点**。基于此，`mRNA` 列的 sense 序列即为靶 mRNA。
- **靶位点（19nt）**：取自 `mRNA` 列的 **中间 19nt**（即 [19:38]），与 `antiRNA(guide)` / 既有靶位点核对一致（Holen 50/50 吻合）。
- **57nt = 19 上游 + 19 靶位点 + 19 下游**（对齐 OligoFormer FLANK=19 约定）。
- 序列统一大写，仅保留 `A/U/G/C`。

### 3.2 侧翼来源（是否编造）

| Ohnishi（55 行） | ⚠️ 仅提供 **19nt 靶位点**，无任何侧翼/转录本全长/坐标 | 留空（不编造），note 说明 |

## 4. 任务 2 · 沉默效率归一化到 [0,1]

### 4.1 参照的 OligoFormer 约定
- 官方仓库 `data/*.csv` 的 `label` 已落在 **[0,1]**（如 `data/Hu.csv` min 0.0 / max 1.0；原始 `raw/` 中为 1.34 量级，经 `label/最大值` 类缩放进入 0–1）。
- 本处理沿用“**把沉默效率映射到 [0,1]**”这一约定方向，对**已是 0–1 沉默效率且方向一致**的样本做 min–max 归一化。

### 4.2 归一化范围（min / max）
- 只把“方向一致、本身就是 0–1 沉默效率”的样本纳入归一化池：**Holen 全部 50 行 + Ohnishi 43 个非负值**。
- 归一化池统计：`min = 0.0140`，`max = 0.9200`。
- **换算公式**：
  ```
  x' = (x − 0.0140) / (0.9200 − 0.0140)
  ```
- 用上式得到全部值落在 **[0,1]**，保留 4 位小数。

### 4.3 各来源是否归一化
| 来源 | 是否归一化 | 说明 |
|------|-----------|------|
| Holen（50 行） | ✅ | 0–1 沉默效率，方向一致 |
| Ohnishi（43 个非负值） | ✅ | 0–1 沉默效率，方向一致 |
| Ohnishi（12 个负值） | ❌ | 负值为 fold 换算伪效率/低于检测限，非有效沉默效率 |
| Birmingham（362） | ❌ | 量纲为 log2 比值（off-target 抑制），非沉默效率 |
| HIVsirDB（179） | ❌ | 量纲为 fold/IC50 |
| Amarzguioui（13） | ❌ | 剩余% 或文本（方向相反） |
| Schwarz（10） | ❌ | IC50 nM（越低越强，方向相反） |
| Ui-Tei（5） | ❌ | 无数值（仅图6柱状图） |

> **结果**：`silencing_efficiency_norm` 共填 **93 行**（Holen 50 + Ohnishi 43），其余 **581 行留空**，每行 `silencing_efficiency_norm_note` 写明未归一化的原因（量纲/方向/文本/负值）。

### 4.4 为何不强行做跨量纲换算
IC50、log2 比值、fold、剩余%、0–1 效率是**不同物理量**，且部分**方向相反**（IC50/剩余% 越低越强，fold/log2 越高越强）。若除以 max 或取倒数强行统一后做全局 min–max，会引入较大失真、也无生物学意义，故按你的选择**不做**。

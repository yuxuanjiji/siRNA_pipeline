# 来源与许可说明（data/文献来源/）

本目录只收录**可从公开文献中提取的数值型数据**与**CC-BY 许可的材料**。
按《附件5》「数据说明与获取方式（不上传受限数据，注明来源与许可）」，
以下内容**不入库**，请按命令自行获取：

| 未入库内容 | 原因 | 获取方式 |
|---|---|---|
| 出版商论文 PDF（`参考文献\*.pdf`） | 出版商版权 | 见 `data/README.md` §5 与各条目 DOI |
| 出版商论文全文提取（`gki785.pdf.txt`、`nar_33_15_4704__1.pdf.txt`） | 版权 | 按 DOI 从出版商或 PMC 获取 |
| 出版商图片（`*.png`，共 18 张，约 11 MB） | 版权 | 按 DOI 在图注中说明的补充材料处获取 |
| 出版商补充材料压缩包（`_research_src\*.zip`） | 再分发条款不明 | 按 DOI/PMC 从出版商站点获取 |
